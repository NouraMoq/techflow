# الملخّص التنفيذي والتشغيلي للتسليم — صانع المحتوى

**المنتج:** صانع المحتوى (Content Maker) · **الشركة:** نوفاميتريكس (NovaMetrics) · **الشعار:** من الفكرة إلى التأثير
**تاريخ التسليم:** يوليو ٢٠٢٦ · **حالة المشروع:** جاهز للنشر التجريبي (Pilot-ready)

> ⚠️ **تنبيه مهم:** هذه وثيقة تسليم تشغيلية. الأسعار أولية لاختبار السوق ولا تشمل ضريبة القيمة المضافة عند
> انطباقها. القوالب القانونية والامتثالية **تشغيلية** وتحتاج **مراجعة مختص قانوني/مالي مرخّص** قبل الاستخدام التجاري.

## ١) نظرة عامة تنفيذية

**صانع المحتوى** نظام تشغيل متكامل لإدارة محتوى المشاهير وصنّاع المحتوى وفرقهم ووكالاتهم — من الاستراتيجية
والأفكار والسيناريوهات، مرورًا بالإنتاج والتصوير والموافقات والنشر، وصولًا إلى التحليلات والتوصيات والحملات
التجارية والعقود والامتثال والسمعة. يبدأ بـ **TikTok** وقابل للتوسّع لمنصات أخرى عبر **نمط المحوّل (Adapter)**،
ويُقدَّم بثلاثة نماذج: **استخدام ذاتي / خدمة مُدارة / وكالة** فوق بنية **متعددة العملاء (Multi‑Tenant)** معزولة.

## ٤) البنية التقنية

- **الواجهة/الخادم:** Next.js 14 (App Router) + TypeScript + React 18 · **قاعدة البيانات:** Prisma ORM (SQLite للتطوير، **PostgreSQL للإنتاج** — المخطط محمول ومُثبت الصلاحية).
- **المصادقة:** جلسة موقّعة (JWT/HS256 عبر `jose`) في كوكي httpOnly + تجزئة bcrypt · **التحقق:** Zod على كل إجراء.
- **تعدد العملاء:** `tenantId` على كل كيان حساس + عزل صارم في كل استعلام (كتابة وقراءة).
- **الصلاحيات:** RBAC مركزي (`can(role, permission)`) يحكم الواجهة والإجراءات.
- **أنماط قابلة للتوسّع:** محوّلات (Adapters) للنشر (TikTok حقيقي + Mock) والتخزين (S3 حقيقي + محلي) — إضافة مزوّد جديد = تسجيله في السجل فقط.
- **قابلية التتبّع:** `AuditLog` + `createdBy/updatedBy/timestamps/deletedAt` (حذف ناعم) على الكيانات الحساسة.

## ٥) التشغيل السريع

**النموذج التفاعلي (بلا خادم/تبعيات):**
```bash
cd techflow && python3 -m http.server 8777
# النموذج:    http://localhost:8777/app/index.html
# التعريفي:   http://localhost:8777/index.html
```

**التطبيق الإنتاجي (تطوير محلي — SQLite):**
```bash
cd techflow/content-maker
npm install --legacy-peer-deps
npm run prisma:generate && npm run prisma:push && npm run seed
npm run dev            # http://localhost:3000
```
**حسابات تجريبية (كلمة المرور `password123`):** `creator@example.sa` (عميل) · `content@example.sa`/`writer@example.sa` (فريق) · `admin@novametrics.sa` (إدارة نوفاميتريكس).

**النشر بـ Docker + PostgreSQL:**
```bash
cd content-maker && export AUTH_SECRET="$(openssl rand -base64 48)"
docker compose up --build      # PostgreSQL + التطبيق على :3000
```
التفاصيل الكاملة في **[content-maker/DEPLOYMENT.md](../content-maker/DEPLOYMENT.md)**.

## ٦) الاختبارات والجودة

- **اختبارات الوحدة (Vitest) — ٢١:** صلاحيات RBAC، محوّلات التكامل، حوارس رفع الملفات (النوع/الحجم/التعقيم). `npm test`.
- **اختبارات E2E (Playwright) — ١٧:** تقود المتصفح فعليًا وتغطّي المصادقة، **عزل بيانات العملاء**، الصلاحيات، إنشاء فكرة، اعتماد، بوابة المشهور، تصدير CSV، الوضع التجريبي، رفع/تنزيل ملف عبر رابط موقّع. `npm run e2e`.
- **التكامل المستمر (CI):** `.github/workflows/content-maker-ci.yml` — وحدة+بناء على SQLite، ثم **E2E على PostgreSQL حقيقية** (تكافؤ إنتاج).
- **مراجعة أمنية (اجتيزت):** كل عمليات الكتابة محصورة بـ `tenantId`؛ كل إجراء/مسار محميّ بالمصادقة والصلاحية؛ لا أسرار في المصدر.

## ٧) الأمن والخصوصية

- تجزئة كلمات المرور (bcrypt) · جلسة موقّعة httpOnly (تُفعَّل `secure` تلقائيًا في الإنتاج/HTTPS).
- **لا أسرار في الكود أو الواجهة**؛ `.env` و`*.db` و`.storage/` في `.gitignore`. مفاتيح التكامل مراجع `secret://` لا رموزًا خام.
- رفع ملفات آمن (تحقّق نوع/حجم، رفع خادمي)، وتحميل عبر **روابط موقّعة قصيرة العمر** (Presigned/محلي) — دون كشف مفاتيح أو روابط دائمة.
- `AuditLog` لكل حدث حسّاس · حذف ناعم · حماية من Path‑Traversal في التخزين المحلي.
- تنبيه: مراجعة **نظام حماية البيانات الشخصية (PDPL)** وسياسات الاحتفاظ/التصدير/الحذف تحتاج اعتماد مختص. راجع `docs/security-and-privacy-ar.md`.

## ٨) الالتزامات والمبادئ الحاكمة

- **عربي أولًا / RTL كامل** — الكود والتعليقات بالإنجليزية، الواجهة بالعربية.
- **لا تكاملات وهمية:** لا يُدّعى نجاح نشر قبل تأكيد الواجهة الرسمية؛ الوضع التجريبي (Mock) **معلَّم بوضوح**.
- **لا جمع بيانات غير مصرّح:** رادار الترندات والجمهور بإدخال يدوي/مصادر رسمية لاحقًا — لا Web Scraping مخالف، ولا طلب كلمات مرور حسابات TikTok.
- **لا اختلاق أرقام:** التوصيات مُشتقّة من بيانات الحساب مع تسجيل «الأساس» لكل توصية.
- **القوالب القانونية تشغيلية** لا بديلًا عن المحامي.

## ٩) ما يحتاج مفاتيح/خدمات خارجية (لم يُفعّل — البنية جاهزة)

| البند | الحالة | ما يلزم |
|---|---|---|
| نشر TikTok **المباشر** | Adapter جاهز + Mock يعمل | تسجيل التطبيق لدى TikTok + OAuth + مفاتيح رسمية |
| تخزين **S3** حقيقي | Adapter جاهز + محلي يعمل | ضبط `S3_*` (دلو + مفاتيح + منطقة) |
| **الفوترة/الدفع** | نموذج باقات/اشتراك موجود | ربط مزوّد دفع سعودي (طبقة مستقلة) |
| ترقية المصادقة إلى **Auth.js** | مصادقة آمنة تعمل حاليًا | اختياري — لتوحيد مزوّدي الدخول لاحقًا |
| **PostgreSQL** الإنتاج | مخطط محمول + Migration مُلتزمة | قاعدة PostgreSQL مُدارة + نسخ احتياطي |

## ١٠) المخاطر والافتراضات الرئيسية

- **موافقة واجهة TikTok** غير مضمونة التوقيت — البنية تعمل بالوضع التجريبي حتى ذلك الحين.
- **الأسعار أولية** لاختبار السوق؛ تُعدّل بعد حساب التكلفة الفعلية ومقابلات العملاء.
- **تغيّر الأنظمة** (إعلان/امتثال/خصوصية) — قوائم الامتثال قابلة للتعديل من لوحة الإدارة، مع تنبيه «يتطلب تحققًا نظاميًا محدثًا».
- التفاصيل الكاملة في `docs/assumptions-and-risks-ar.md`.
