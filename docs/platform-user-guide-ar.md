## 1) كيف تبدأ — الدخول والتنقّل

**تسجيل الدخول:** افتح رابط المنصة (محليًا `http://localhost:3000`، ومستقبلًا `app.novametrics.sa`) → أدخل البريد وكلمة المرور.
حسابات تجريبية للتعلّم (كلمة المرور `password123`):
- `creator@example.sa` — المشهور / صانع المحتوى (يرى لوحة العميل).
- `content@example.sa` / `writer@example.sa` — أعضاء فريق بأدوار مختلفة.
- `admin@novametrics.sa` — إدارة نوفاميتريكس (يرى لوحة الإدارة).

**التنقّل:** الشريط الجانبي (على اليمين، RTL) مقسّم إلى مجموعات:
- **الرئيسية:** الرئيسية · بوابة المشهور
- **الاستراتيجية والمحتوى:** الهوية والاستراتيجية · أعمدة المحتوى · بنك الأفكار · رادار الترندات · السيناريوهات
- **الإنتاج:** المحتوى والإنتاج · جلسات التصوير · التقويم التحريري · المهام · الموافقات · مكتبة الملفات · النشر على TikTok
- **التجارة:** الحملات والإعلانات · العقود والفواتير
- **الحوكمة:** الامتثال · السمعة والأزمات
- **الأداء والفريق:** التحليلات · التوصيات الذكية · الجمهور والأسئلة · التقارير · التكاملات · الفريق والصلاحيات
- **نوفاميتريكس (للإدارة فقط):** لوحة الإدارة · الباقات · إعدادات الامتثال · سجل التدقيق

> **مبدأ مهم:** ما تراه يعتمد على **دورك**. مثلًا الكاتب يرى محرّر السيناريو للتحرير، والمشهور يعتمد فقط. الأزرار غير المتاحة لدورك لا تظهر.

## 2) شرح كل نافذة بالتفصيل

> لكل نافذة: **الغرض** (لماذا موجودة) · **ما تراه** · **ما تفعله**.

### 🏠 الرئيسية `/dashboard`
- **الغرض:** لمحة سريعة على وضع المحتوى اليوم.
- **ما تراه:** بطاقات أرقام (أفكار نشطة، مشاريع قيد الإنتاج، بانتظار الموافقة، مشاهدات)، وجدول «الإنتاج القادم» بأقرب المشاريع حسب الاستحقاق.
- **ما تفعله:** تتابع الحالة بسرعة، وتنتقل من هنا لأي وحدة.

### 📱 بوابة المشهور `/portal`
- **الغرض:** تجربة **مبسّطة للمشهور** (بلا تعقيد لوحة الوكالة)، مناسبة للجوال.
- **ما تراه:** ما يحتاج موافقتك · تصوير قادم · خطة الأسبوع · المحتوى القادم · مؤشراتك · عقد/فرصة مهم · تنبيهات.
- **ما تفعله:** تعتمد أو تطلب تعديلًا بضغطة، وتسجّل **فكرة سريعة** تدخل بنك الأفكار مباشرة.

### 🎯 الهوية والاستراتيجية `/strategy`
- **الغرض:** تعريف العلامة الشخصية (المرجعية لكل قرار محتوى).
- **ما تراه:** الرؤية، الرسالة، الوعد للجمهور، تحليل SWOT (قوة/ضعف/فرص/مخاطر)، أهداف ٣/٦/١٢ شهرًا، النسخة المعتمدة.
- **ما تفعله:** تراجع الاستراتيجية وتعتمدها؛ كل تغيير يُحفظ كإصدار.

### 🧱 أعمدة المحتوى `/pillars`
- **الغرض:** توزيع المحتوى على محاور استراتيجية بنسب متوازنة.
- **ما تراه:** بطاقات الأعمدة (تعليمي/ترفيهي/قصصي/تجاري/تحويل) بنسبها المستهدفة ومؤشر كل عمود، وتنبيه إن لم يكن المجموع ١٠٠٪.
- **ما تفعله:** تضبط النسب لتوازن الخطة.

### 💡 بنك الأفكار `/ideas`
- **الغرض:** مخزن منظّم للأفكار من المسودة إلى النشر.
- **ما تراه:** لوحة **Kanban** بأعمدة الحالة (مسودة → معتمدة → قيد الإنتاج → منشورة)، وبطاقات الأفكار بدرجة الانتشار والملاءمة والوسوم.
- **ما تفعله:** «فكرة جديدة» لإضافتها، و«نقل إلى» لتحريكها بين المراحل.

### 📡 رادار الترندات `/trends`
- **الغرض:** رصد الترندات المناسبة واتخاذ قرار بشأنها.
- **ما تراه:** بطاقات ترندات (نوع/صوت/هاشتاق/درجة نمو/عمر متوقع/ملاءمة/مخاطر/زاوية مقترحة) وقرار كل ترند.
- **ما تفعله:** «إضافة ترند» يدويًا، وقرار **استخدام/تجاهل**. *(إدخال يدوي فقط — لا جمع غير مصرّح.)*

### 📝 السيناريوهات `/scripts`
- **الغرض:** كتابة سيناريوهات احترافية بإصدارات وموافقات.
- **ما تراه:** قائمة السيناريوهات بحالاتها؛ وعند فتح واحد: محرّر بكل الحقول (Hook، مقدمة، جسم، CTA، نص على الشاشة، وصف، هاشتاقات، موسيقى، ملابس، موقع، مدة، إفصاح إعلاني)، **سجل الإصدارات**، وأزرار سير المراجعة.
- **ما تفعله:** تحرّر وتحفظ، «إرسال للمراجعة» ثم اعتماد/طلب تعديل، وزر **Teleprompter** لعرض النص كبيرًا أثناء التصوير مع تحكم في السرعة.

### 🔧 المحتوى والإنتاج `/production`
- **الغرض:** إدارة خط الإنتاج (Workflow) لكل مقطع.
- **ما تراه:** المراحل الـ١٨ (فكرة → … → نشر → تحليل)، وجدول المشاريع بالمرحلة الحالية والمسؤول والاستحقاق ونسبة التقدّم.
- **ما تفعله:** تتابع تقدّم كل مشروع وتحرّكه بين المراحل.

### 🎥 جلسات التصوير `/shoots`
- **الغرض:** تنظيم أيام التصوير (Call Sheet).
- **ما تراه:** بطاقات الجلسات (تاريخ/موقع/فريق/تكلفة/حالة)، و**قائمة اللقطات** لكل جلسة (سيناريو/ملابس/حالة) مع عدّاد إنجاز.
- **ما تفعله:** «جلسة تصوير» جديدة، وتحديث حالة كل لقطة (بانتظار → تم التصوير → معتمد)، وتقدّم حالة الجلسة.

### 🗓️ التقويم التحريري `/calendar`
- **الغرض:** رؤية شهرية تجمع كل المواعيد في مكان واحد.
- **ما تراه:** شبكة الشهر مرمّزة بالألوان، تجمّع تلقائيًا: **النشر، التصوير، التسليمات، نهايات العقود، الفواتير** + عناصر يدوية، مع تمييز اليوم وتنبيه توازن.
- **ما تفعله:** «عنصر جديد» (نشر/مناسبة/يوم عدم نشر)، والتنقّل بين الأشهر.

### ✅ المهام `/tasks`
- **الغرض:** توزيع مهام الفريق المرتبطة بالمحتوى.
- **ما تراه:** لوحة بحالات (قيد التنفيذ/بانتظار المراجعة/لم تبدأ/مكتملة)، وبطاقات المهام بالأولوية والمسؤول.
- **ما تفعله:** تتابع مهامك ومهام الفريق.

### 👍 الموافقات `/approvals`
- **الغرض:** مراجعة واعتماد المحتوى بسجل موثّق **يمنع نشر نسخة غير معتمدة**.
- **ما تراه:** بطاقات العناصر المنتظرة (النوع/النسخة/المرسل).
- **ما تفعله:** **اعتماد** أو **طلب تعديل** (لمن يملك الصلاحية).

### 📁 مكتبة الملفات `/assets`
- **الغرض:** حفظ الأصول الرقمية (فيديو/صور/موسيقى/عقود…).
- **ما تراه:** بانر وضع التخزين (S3 أو محلي)، وجدول الملفات (نوع/مجلد/حجم/إصدارات/انتهاء الحقوق)، وتنبيه الحقوق على وشك الانتهاء.
- **ما تفعله:** **رفع ملف** فعلي، و**تنزيله** عبر رابط موقّع آمن، وحذفه. *(المفاتيح لا تظهر في الواجهة.)*

### 🚀 النشر على TikTok `/publishing`
- **الغرض:** تجهيز المحتوى ونشره عبر طبقة التكامل.
- **ما تراه:** حالة اتصال TikTok (تجريبي/مباشر)، المحتوى الجاهز للنشر، وقائمة مهام النشر بحالاتها.
- **ما تفعله:** «تجهيز نشر» ثم «نشر عبر التكامل»، أو تسجيل رابط منشور **يدويًا**. *(لا يُقال «منشور» إلا بعد تأكيد الواجهة الرسمية.)*

### 🔌 التكاملات `/integrations`
- **الغرض:** ربط المنصات والخدمات (Integration Hub).
- **ما تراه:** بطاقات المنصات بحالاتها (غير متصل/متصل/يحتاج إعادة تصريح/…)، وبانر «الوضع التجريبي (Mock)» عند غياب المفاتيح.
- **ما تفعله:** ربط/فصل/إيقاف مؤقت.

### 📊 التحليلات `/analytics`
- **الغرض:** متابعة الأداء. *(بيانات تجريبية في هذه النسخة — تُربط لاحقًا بالمصادر الرسمية.)*
- **ما تراه:** مؤشرات (مشاهدات/تفاعل/متابعون/إكمال)، ورسم نمو شهري، وأفضل الأوقات.

### ✨ التوصيات الذكية `/recommendations`
- **الغرض:** تحويل البيانات إلى إجراءات.
- **ما تراه:** بطاقات توصيات **مشتقّة من بيانات حسابك فعليًا** (أعمدة غير متوازنة، ترند يوشك الانتهاء، فاتورة متأخرة، فكرة معتمدة بلا سيناريو…) مع **الأساس** ومستوى الثقة والمسؤول.
- **ما تفعله:** «توليد التوصيات»، ثم **تطبيق** (يتحوّل إلى مهمة) أو **تأجيل**.

### 💬 الجمهور والأسئلة `/audience`
- **الغرض:** إدارة تفاعل الجمهور وتحويله إلى محتوى.
- **ما تراه:** أكثر الأسئلة تكرارًا بتصنيفها، وقوائم الردود المعتمدة والكلمات الحساسة.
- **ما تفعله:** «سؤال جديد» يدويًا، و**«حوّل لفكرة»** (ينشئ فكرة في البنك). *(إدخال يدوي فقط.)*

### 🧾 التقارير `/reports`
- **الغرض:** تقارير جاهزة للطباعة والتصدير.
- **ما تراه:** ٧ تقارير (تنفيذي، المحتوى، الأعمدة، الفريق، العقود، الإيرادات، الامتثال).
- **ما تفعله:** «عرض/طباعة» (طباعة ← حفظ PDF) أو **«تصدير CSV»** (يفتح في Excel).

### 🤝 الحملات والإعلانات `/campaigns`
- **الغرض:** إدارة العلامات والفرص التجارية (CRM مصغّر).
- **ما تراه:** لوحة فرص (فرصة محتملة → عقد → منشور → محصّل)، جدول العلامات، والحملات مع نسبة التسليمات.
- **ما تفعله:** «فرصة جديدة»، وتقديم الفرصة بين المراحل.

### 📄 العقود والفواتير `/contracts`
- **الغرض:** حفظ العقود وتتبّع الالتزامات والمستحقات.
- **ما تراه:** بطاقات العقود (قيمة/مدة/حصرية/حقوق/دفع)، **تنبيهات الالتزامات التي قد تُنسى** (انتهاء الحصرية/الحقوق، بقاء المنشور، التسليم، الدفعات)، وجدول الفواتير.
- **ما تفعله:** تتابع الالتزامات قبل تجاوز مواعيدها. *(القوالب تشغيلية — تحتاج مراجعة قانونية.)*

### 🛡️ الامتثال `/compliance`
- **الغرض:** التحقق من مطابقة المحتوى التجاري.
- **ما تراه:** قائمة تحقّق سعودية (إعلاني؟ إفصاح؟ تراخيص؟ حقوق؟ …)، وسجل المراجعات بحالتها.
- **ما تفعله:** «مراجعة امتثال» بالإجابة على القائمة (نعم/لا/لا ينطبق) فتُحسب الحالة تلقائيًا. *(لا يُدّعى امتثال نهائي — المراجعة القانونية لمختص مرخّص.)*

### 🚨 السمعة والأزمات `/crisis`
- **الغرض:** إدارة المواقف والأزمات بأدلة جاهزة.
- **ما تراه:** حالات الأزمات (خطورة/مصدر/رد مقترح/ردود ممنوعة/حالة)، وشبكة **Playbooks** (خطأ في إعلان، تسريب محتوى…).
- **ما تفعله:** «تسجيل موقف»، وتحديث حالة الأزمة عبر مراحلها.

### 👥 الفريق والصلاحيات `/team`
- **الغرض:** إدارة الأعضاء ورؤية من يستطيع فعل ماذا.
- **ما تراه:** بطاقات الأعضاء بأدوارهم، و**مصفوفة الصلاحيات (RBAC)**.

### 🏢 لوحة نوفاميتريكس (للإدارة فقط)
- **`/admin` لوحة الإدارة:** العملاء عبر الحسابات، الإيراد الشهري المتكرر (MRR)، حالة الاشتراكات.
- **`/admin/plans` الباقات:** الباقات الخمس وأسعارها وحدودها والإضافات.
- **`/admin/compliance` إعدادات الامتثال:** **تفعيل/تعطيل بنود قائمة التحقق** (لأن الأنظمة تتغيّر).
- **`/admin/audit` سجل التدقيق:** سجل الأحداث الحساسة عبر الحسابات.

## 3) آلية الاستخدام — تدفّقات عملية (خطوة بخطوة)

### أ) التهيئة الأولية (عند بدء عميل جديد)
1. الهوية والاستراتيجية → أدخل الرؤية/الرسالة/القيم واعتمد النسخة.
2. أعمدة المحتوى → اضبط النسب لتصبح ١٠٠٪.
3. الفريق والصلاحيات → ادعُ الأعضاء وحدّد أدوارهم.
4. التكاملات → اربط TikTok (تجريبي الآن، مباشر عند توفر المفاتيح).

### ب) من الفكرة إلى النشر (الدورة الكاملة) ⭐
1. **بنك الأفكار** → أضف فكرة (أو «حوّل لفكرة» من الجمهور/الترندات) → انقلها إلى **معتمدة**.
2. **السيناريوهات** → أنشئ سيناريو مرتبطًا بالفكرة، اكتب الحقول → **إرسال للمراجعة**.
3. **الموافقات** → المعتمد النهائي يعتمد السيناريو.
4. **جلسات التصوير** → أنشئ جلسة، جهّز قائمة اللقطات، وصوّر (حدّث حالة كل لقطة).
5. **مكتبة الملفات** → ارفع المواد الخام والنسخة النهائية.
6. **المحتوى والإنتاج** → حرّك المشروع عبر مراحل المونتاج والاعتماد.
7. **الموافقات** → اعتماد نهائي للنسخة المنشورة.
8. **النشر على TikTok** → جهّز الوصف والهاشتاقات وانشر (أو سجّل الرابط يدويًا).
9. **التحليلات + التوصيات** → تابع الأداء ونفّذ التوصيات المقترحة.

### ج) إدارة حملة تجارية (من فرصة إلى تحصيل)
الحملات (فرصة جديدة) → تقديمها بين المراحل → العقود (سجّل العقد والالتزامات) → التقويم (مواعيد التسليم) → الإنتاج والنشر → الفواتير (تتبّع الدفع) → تقرير الحملة.

### د) الخدمة المُدارة (فريق نوفاميتريكس)
جلسة استراتيجية شهرية → تخطيط المحتوى في التقويم → توليد الأفكار والسيناريوهات → متابعة الإنتاج والموافقات → تقرير شهري + توصيات (من التقارير).

### هـ) قبل أي نشر إعلاني
مرّ على **الامتثال** → «مراجعة امتثال» (إفصاح إعلاني؟ حقوق؟ تراخيص؟) → عالج ما هو «يحتاج معالجة» قبل النشر.

<a id="4"></a>
## 4) من يفعل ماذا (ملخّص الأدوار)

| الدور | أبرز ما يفعله |
|---|---|
| المشهور / صانع المحتوى | يعتمد المحتوى، يسجّل أفكارًا، يرى بوابته المبسّطة والتحليلات |
| مدير المحتوى | يدير الأفكار والسيناريوهات والإنتاج والموافقات والفريق |
| كاتب المحتوى | يكتب ويحرّر السيناريوهات، يضيف أفكارًا |
| المونتير / المصور | يرفع الملفات، يشارك في جلسات التصوير |
| المعتمد النهائي | يعتمد/يرفض المحتوى |
| مدير الأعمال | العقود والفواتير والحملات والامتثال والأزمات |
| نوفاميتريكس (إدارة) | العملاء والباقات والاشتراكات وإعدادات الامتثال والتدقيق |

> الأزرار تظهر حسب الدور: ما لا تملك صلاحيته لا يظهر لك، والمحرّرات تصبح «عرض فقط».

## 5) أسئلة شائعة

**هل بياناتي معزولة عن العملاء الآخرين؟** نعم — كل حساب معزول تمامًا، ولا يرى أي طرف بيانات طرف آخر (مُثبت باختبارات).
**هل النشر على TikTok حقيقي الآن؟** يعمل بالوضع التجريبي (Mock) بوضوح؛ يُفعّل المباشر عند تسجيل التطبيق والحصول على المفاتيح.
**من أين أصدّر تقريرًا PDF؟** التقارير → اختر التقرير → «عرض/طباعة» ← حفظ PDF من المتصفح، أو «تصدير CSV».
**كيف أضيف فكرة بسرعة كمشهور؟** من **بوابة المشهور** → «سجّل فكرة سريعة».
**الأسعار نهائية؟** لا — أولية لاختبار السوق، لا تشمل الضريبة، وتحتاج اعتماد الشركة.
