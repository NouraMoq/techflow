# الأدوار والصلاحيات (RBAC) — «صانع المحتوى»

> **الشركة:** نوفاميتريكس | NovaMetrics — «من الفكرة إلى التأثير»
> **إصدار الوثيقة:** 1.0 (اختبار سوق) — **التاريخ:** 2026-07-18
> **مرجع:** `product-requirements-document-ar.md`

---

## 1. المبادئ

- **تحكّم وصول قائم على الأدوار (RBAC)** داخلي فوق Auth.js.
- **عزل صارم بين المستأجرين:** كل صلاحية تُقيَّد داخل نطاق المستأجر (`tenantId`)؛ لا يتجاوز أي دور حدود مستأجره إلا أدوار نوفاميتريكس المصرّح لها ضمن نطاقها التشغيلي.
- **أقل امتياز (Least Privilege):** يُمنح الدور أدنى صلاحية تكفي لمهمته.
- **الفصل بين نوعين من الأدوار:** أدوار إدارة نوفاميتريكس (الجهة المشغّلة) وأدوار حساب العميل.
- **قابلية التدقيق:** كل إجراء حسّاس مسجّل (Audit Info) مع الحذف الناعم.

---

## 2. أدوار إدارة نوفاميتريكس (Operator Roles)

| الدور | الوصف |
|------|-------|
| Super Admin | صلاحية عليا على المنصة وإعداداتها وكل المستأجرين ضمن الحوكمة. |
| مدير خدمة العملاء | يشرف على فرق الحسابات وجودة الخدمة عبر العملاء. |
| مدير الحساب | يدير محفظة عملاء محدّدة (خدمة مُدارة) ويقدّم التخطيط والتوصيات. |
| محلل الأداء | يحلّل بيانات الأداء ويبني التوصيات والتقارير. |
| مسؤول الفوترة | يدير الاشتراكات والفواتير والمدفوعات وحدود الاستخدام. |
| مسؤول الدعم | يعالج طلبات الدعم ضمن صلاحية محدودة. |
| مسؤول الامتثال | يتابع الالتزامات النظامية وإثباتها (بإشراف قانوني مرخّص). |

## 3. أدوار حساب العميل (Tenant Roles)

| الدور | الوصف |
|------|-------|
| المشهور / صانع المحتوى | صاحب العلامة؛ اعتماد نهائي ورؤية شاملة لحسابه. |
| مدير الأعمال | إدارة الأعمال والعقود والفريق والصلاحيات. |
| مدير المحتوى | إدارة التقويم وسير العمل والمهام والجودة. |
| الكاتب | إنشاء وتعديل الأفكار والسيناريوهات. |
| المصوّر | جلسات التصوير ورفع الأصول الخام. |
| المونتير | معالجة الأصول وتسليم المخرج للمراجعة. |
| المصمم | تصميم الأصول البصرية ورفعها. |
| محلل البيانات | الاطلاع على التحليلات وبناء التقارير. |
| مسؤول الإعلانات والشراكات | إدارة الفرص والحملات والعقود التجارية. |
| مراجع / معتمد نهائي | اعتماد أو رفض المحتوى قبل النشر. |
| عرض فقط | اطلاع دون تعديل. |

## 4. الإجراءات المشمولة بالمصفوفة

إنشاء فكرة، تعديل فكرة، كتابة سيناريو، الاطلاع على العقود/الأسعار، رفع ملفات، اعتماد، رفض، جدولة، نشر، الاطلاع على التحليلات، إدارة الفريق، البيانات المالية، حذف محتوى، تصدير تقارير.

> الرموز: ✓ مسموح كامل — ✗ غير مسموح — جزئي = مسموح ضمن نطاق/حدود محدّدة.

**ملاحظات:**
- «النشر» غير ممنوح لأدوار نوفاميتريكس (عدا Super Admin ضمن الحوكمة) احتراماً لملكية العميل لقرار النشر؛ الخدمة المُدارة تُخطّط وتتابع وتعتمد داخلياً ثم يعتمد العميل نهائياً عبر بوابته.
- «رفض» ممنوح لمسؤول الامتثال لإيقاف محتوى مخالف نظامياً (بإشراف قانوني مرخّص).
- «البيانات المالية» تتركّز في مسؤول الفوترة وSuper Admin.

## 7. قواعد حاكمة إضافية

1. أي صلاحية «جزئي» تُفصَّل عند التنفيذ بقواعد نطاق (مثال: الكاتب يعدّل أفكاره فقط، لا أفكار غيره).
2. الاعتماد النهائي للنشر يبقى بيد المشهور/المعتمد النهائي أو مدير الأعمال بحسب إعداد المستأجر.
3. الحذف افتراضياً «حذف ناعم»؛ الحذف النهائي يتطلب صلاحية عليا وتسجيل تدقيق.
4. تصدير التقارير يخضع لحدود الباقة.
5. لا يرى أي دور بيانات مستأجر آخر؛ أدوار نوفاميتريكس مقيّدة بمحفظتها المخوّلة.
